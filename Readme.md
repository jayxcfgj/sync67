# sync67

AES67 control & monitoring for PipeWire on Linux.

sync67 is a desktop application for managing, monitoring and controlling AES67 audio streaming workflows on Linux systems using PipeWire.

The project focuses on:

- PTP clock synchronization
- AES67 runtime management
- PipeWire AES67 configuration
- realtime monitoring
- live audio networking workflows

sync67 is designed for professional and semi-professional Linux audio environments such as:

- live playback systems
- multitrack recording rigs
- rehearsal setups
- studio integration
- AES67/Dante interoperability

---

# Goals

sync67 aims to provide a centralized control interface for:

- `ptp4l`
- PipeWire AES67
- realtime synchronization monitoring
- stream status monitoring
- PipeWire runtime inspection

The project intentionally does NOT replace existing patchbay tools such as:

- qpwgraph
- coppwr
- helvum

Instead, sync67 complements them by handling synchronization and system orchestration.
